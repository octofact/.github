Alternative data that doesn't break — continuous, point-in-time, self-repairing.

Octofact turns the open web into structured, continuously updated datasets for investors and
enterprises. Collection runs on self-healing pipelines: when a source changes shape, the break is
detected and repaired automatically, so every series stays continuous and gap-free.

**Coverage**

- 3.5M+ companies across 27+ global exchanges, full sector coverage
- 20+ linked identifiers — ticker, ISIN, CUSIP, SEDOL, LEI, DUNS, CIK, FIGI, URL and more

**Point-in-time by default**

Every series can be queried as of any date, not just as current. Identifiers resolve as they were
valid on that date, so a backtest sees the ticker or CUSIP that existed then — no look-ahead bias.

**Access**

Explorer UI · API · Python SDK · MCP for AI agents · agentic search · batch exports and warehouse
federation.
